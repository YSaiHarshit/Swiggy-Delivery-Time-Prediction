Swiggy Delivery Time Prediction is a Machine Learning project designed to predict the estimated time required to deliver food orders to customers using factors such as distance, weather, traffic, vehicle type and delivery person details. The project uses Python, Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn for data analysis and model development. It involves data cleaning, Exploratory Data Analysis (EDA), feature engineering, categorical encoding, numerical scaling and train-test splitting. Five regression algorithms, including Linear Regression, Decision Tree, Random Forest, Gradient Boosting and XGBoost, are implemented and compared. Model performance is evaluated using MAE, MSE, RMSE and R² score, followed by hyperparameter tuning to improve performance. The best-performing model and preprocessing objects are saved using Joblib, and a Streamlit application is developed to predict delivery time based on user inputs.
